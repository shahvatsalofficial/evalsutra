11. FAQ and glossary

FAQ

Does EvalSutra run my agent? No. It grades observations you record. Live execution is planned.

Does it use AI or send data anywhere? No. It is deterministic code with no network access.

Can I trust GO_CANDIDATE? It means your rules were met by the evidence you supplied. It is not approval, safety proof or certification.

Why is my result REVIEW instead of pass? Some evidence is missing or weak. The reason code in the report says which field.

Why can a model judge not pass a case? A judge gives an opinion that can be wrong or biased. Evidence from a judge can reveal a problem but never prove success.

Is it free for commercial use? Yes, under Apache-2.0. Keep the licence and NOTICE.

Which editors does it support? Skill files install into Claude Code, Cursor, Codex, Gemini CLI and Copilot folders. Only the file copy is verified. Check each tool's current docs for skill discovery.

Why no dependencies? Smaller attack surface and instant npx start.

How do I add my own check? See Contributor handbook.

Is it on npm? Not yet. Use npx github:shahvatsalofficial/evalsutra.

How do I know the samples are not faked? Every sample file is produced by scripts/build-evidence.mjs from the shipped CLI. Re-run it and diff.

How do I report a bug or vulnerability? Bugs: GitHub issues. Vulnerabilities: private vulnerability reporting, see Security and legal.

Glossary

TermMeaning
AgentA program that uses an AI model and tools to complete tasks
AssertionOne check on one observation
CaseA named scenario with one or more assertions
SuiteA set of cases plus gate thresholds
ObservationRecorded output, tool calls and latency for a case
Evidence sourceWhere an observation came from (actual_run, human_label, ...)
InconclusiveNot enough evidence to say pass or fail
CoverageShare of assertion weight that could be scored
Pass rateShare of scored weight that passed
Critical caseA case whose failure forces NO_GO
GateThe overall decision: NO_GO, REVIEW, GO_CANDIDATE
CanaryA fake secret planted to see if the agent leaks it
Wilson intervalA confidence range for a proportion that behaves well for small samples
pass@kProbability that at least one of k attempts passes
Sign testA test on how many cases got worse versus better
Repro capsuleA folder with redacted inputs and a hash manifest
SkillA SKILL.md instruction file loaded by an AI tool
ReDoSA regular expression that takes exponential time on crafted input
ADRArchitecture decision record

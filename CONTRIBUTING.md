# Contributing
Thank you for improving EvalSutra AI, created by Vatsal Shah. Please open an issue describing the problem and supporting evidence before major API changes. Fork the project; create small PRs with reproducible tests; run `npm test` and `npm run validate`; update feature status and documentation. Never submit real secrets, private training data or unlicensed benchmarks. For security-sensitive reports, follow SECURITY.md rather than a public issue. Claims that an IDE or server integration works must include reproducible proof and host versions. Follow CODE_OF_CONDUCT.md.

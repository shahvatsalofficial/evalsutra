# Roadmap
- **Starter complete locally:** offline replay evaluation; assertions; reports; comparison; 18 automated tests.
- **Next:** richer versioned JSON schemas, hashes/provenance, robust CLI input validation, curated datasets, independent grader calibration, host install dry-run/uninstall.
- **Later:** isolated controlled runner, verified IDE adapters and CI integration, Promptfoo/Inspect imports, OpenTelemetry traces.
- **Advanced:** opted-in provider/local model adapters, calibrated judge evaluation, secure server and optional accessible dashboard.
Status is explicitly not a promise of dates or feature completeness.

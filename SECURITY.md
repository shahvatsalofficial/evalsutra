# Security Policy
This starter only processes local JSON; it does not execute target agents and needs no API keys. **Never evaluate untrusted code outside an authorized sandbox.** Imported outputs are untrusted and should not be rendered as raw HTML. Keep private benchmarks and secrets out of public issues/PRs. Do not add default auto-networking, global installs, unauthorized repo modifications, or unbounded paid model calls. For vulnerabilities, use GitHub private vulnerability reporting when the repository has it enabled or contact its future maintainer through an authorized private channel. No security-contact address is claimed to exist yet. See the threat model in docs/master-claude-prompt.md.
